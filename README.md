## 👨‍💻 About Me

Hello and welcome! I am **Hunain Ahmed**, an ambitious **AI / Machine Learning Engineer** and **Full-Stack Software Developer** passionate about architecting intelligent, high-performance systems from mathematical models all the way to intuitive user experiences.

- 🧠 **AI/ML Focus**: Deep neural networks, Computer Vision, Multi-modal LLMs & agentic workflows, Recommender Systems, and algorithmic optimization.
- 💻 **Engineering Focus**: High-scale web applications, cross-platform mobile architectures, reactive state engines, client-side media manipulation (Canvas 2D / Web Audio), and robust backend microservices.
- ⚡ **Philosophy**: Code should be clean, modular, mathematically sound, and deliver undeniable real-world value with world-class user experience.
